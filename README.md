# C Programming Exercises

A collection of introductory console programs for arithmetic, conditions, comparisons, and unit conversions.

**Stack:** C · GCC

## Contents

`code/` contains independent C source files; this is an exercise collection rather than one application.

## Usage and scope

Compile one program at a time, for example `gcc -Wall -Wextra code/even.c -o /tmp/even-c`, then run `/tmp/even-c`. Review input validation and integer/float handling before reusing these exercises.
